# ADR-008: Query and scripting contracts

Status: accepted for M0–M6.

## Context

The supplied plan fixes Go, PostgreSQL, Goja, Bazel and the separate private GitOps deployment boundary. Preserve those choices while making the application independently testable.

## Decision

Use a bounded typed AST and breadth-level pull on a short repeatable-read, read-only snapshot. Execution-local caches cannot outlive that snapshot. HMAC cursors bind query/space/revisions/expiry; changed revisions require restart. Integers/decimals stay lossless strings on wire and integers become JS bigint.

## Consequences

Validate this decision at its application boundary and report environment-dependent deployment proofs separately in implementation-status.md. No production activation is implied by an application PR.
