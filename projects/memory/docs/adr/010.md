# ADR-010: Release safety and recovery

Status: accepted for M0–M6.

## Context

The supplied plan fixes Go, PostgreSQL, Goja, Bazel and the separate private GitOps deployment boundary. Preserve those choices while making the application independently testable.

## Decision

The application uses explicit lock-protected migrations and rejects incompatible schema at serve startup. Release jobs require native tests and vulnerability scans. Operator-only graph export/import preserves IDs/provenance/history and refuses overwrite. Staged NixOS activation, compatible rollback, off-site backups and OOM recovery VM proofs remain later infrastructure work.

## Consequences

Validate this decision at its application boundary and report environment-dependent deployment proofs separately in implementation-status.md. No production activation is implied by an application PR.
