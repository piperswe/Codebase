# ADR-006: First-class schema with relational enforcement

Status: accepted for M0–M6.

## Context

The supplied plan fixes Go, PostgreSQL, Goja, Bazel and the separate private GitOps deployment boundary. Preserve those choices while making the application independently testable.

## Decision

Attribute/type/source identities are ordinary entities with relational definition projections. A common read_facts view exposes protected metadata as stable virtual facts. Generic EAV writes cannot modify it, and exports restore authoritative rows rather than duplicate virtual facts. This avoids circular bootstrap validation.

## Consequences

Validate this decision at its application boundary and report environment-dependent deployment proofs separately in implementation-status.md. No production activation is implied by an application PR.
